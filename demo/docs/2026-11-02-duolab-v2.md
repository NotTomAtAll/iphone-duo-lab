# DuoLab v2: decisions, not knobs

Date: 2026-11-02. Replaces the knob-first catalog after review ("feels like a debug app", "Compare is a list then side by side", "what is Notes for?").

## What changed and why

| v1 | Problem | v2 |
|---|---|---|
| Lab page = a form of raw knobs | Reads as a debug panel. You must know the APIs to get a meaningful variant. | **Options**: 3–6 curated approaches per topic, each with a verdict, a summary, strengths, costs and what to try. Raw knobs stay as an optional *Fine-tune* page. |
| Compare tab: pick from lists, then show side by side | Abstract choices with nothing to see; the panes broke real layouts (clipped tab bar). | **Option grid with real thumbnails** on every topic page, switchable Open/Folded. Tap a card to run the option full screen; ‹ › pages through the options. |
| Notes tab: starred variant keys | Purpose unclear; the output was internal keys. | **Playbook**: one choice per topic with a reason, progress, and Share as markdown with links back to the live options. This is the team deliverable. |
| Inspector form | Debug look. | **Device** tab with cards: window, safe-area diagram, hinge gauge, reserved regions. |
| Playground pill (close, knobs, HUD, star, move) | Five unexplained icons. | **Option bar**: close, ‹ title · verdict · n of m ›, details, collapse. |

## Thumbnails

Rendered at the measured window size (951×669 open, 466×678 folded) in a hidden `UIWindow` behind the app, snapshotted with `drawHierarchy`, and cached by variant. Two approaches were tried first and rejected:

1. **Scaled live SwiftUI views:** nested NavigationStacks merge into the host's stack (their titles leak into the host bar) and no tab bar draws.
2. **A separate `UIHostingController`, even outside the view-controller chain:** SwiftUI still finds the host's navigation controller through the view hierarchy.

Size-class trait overrides are applied only for the display we're not on. Overriding the current one made TabView pick a sidebar instead of the Duo's vertical bar.

## Data

`LabOption` (id, title, verdict, summary, pros, cons, lookFor, knob preset, optional highlight knob) lives next to each lab. `DecisionStore` persists `[Decision]` (topic, option, tweaks from Fine-tune, rationale, date) and renders the playbook markdown.
